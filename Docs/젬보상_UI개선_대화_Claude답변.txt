## 보고 (지시서: 1118_젬보상_실패계산_수정)

**요약 2줄**
- 실패(사망·그만두기) 시 젬 = 버틴 밤 수 ÷ 3(버림), 최대 2개입니다. 버틴 밤은 밤이 끝나고 아침을 맞을 때 1 늘고, 보스가 나온 뒤에는 늘지 않습니다.
- 결과 화면에 '버틴 밤 n회'를 넣었습니다. 기존 FailHigh / FailLow / MinDay 변수는 지웠고, 특수 젬 드롭 조건은 '버틴 밤 3회 이상'으로 바꿨습니다.

**완료 조건 확인 (플레이)**
- 시작 직후 사망: 젬 0개 ✓
- 밤 3회 생존 후 사망: 젬 1개 ✓
- 실패 보상 상한: 밤 6·9·12회 모두 2개 ✓ (계산 함수로 확인)
- 그만두기: 밤 7회 상태에서 2개 지급 ✓ (결과 화면 없이 지급만 하고 타이틀로 갑니다)

**8번 확인 값 (수정 안 함)**
- **낮 길이:** 75초
- **밤 길이:** 60초
- **보스 등장:** 게임 시간 600초(Main 씬의 maxGameTime 값)입니다. 5일차 낮 60초쯤에 해당합니다.
- **보스전 제한 시간:** 없습니다. 보스를 잡거나 사망할 때까지 계속됩니다.
- **클리어 1판 소요 시간:** 600초(10분)에 보스전 시간을 더한 값입니다. 보스전은 제한이 없어서 정확히 계산할 수 없습니다. 레벨업·아침 선택·상점으로 멈춘 시간은 빠져 있습니다.
- **참고:** 끝없는 밤 없이 버틸 수 있는 밤은 최대 4회라서, 보통 실패 보상은 최대 1개입니다. 2개는 끝없는 밤으로 밤 수가 늘어야 받을 수 있습니다.

## UI 수정
- **메뉴 배경과 버튼 (Panel_2):**
  - 화면 테두리를 Panel_2의 나무 액자(등불·깃발·잎·돌 포함)로 바꿨습니다.
  - 제목판은 잎 장식판, 버튼은 금테 버튼입니다. 메인 메뉴와 젬 화면도 같은 버튼을 씁니다.
- **젬 관리:**
  - 왼쪽 칸에 젬 상인 마스코트를 넣었습니다. 오른쪽을 보고, 18프레임 애니메이션이 움직입니다.
  - 보관함에 '전체 해제' 버튼을 넣었습니다.
  - 선택한 젬 이름은 한 줄로 나옵니다. 길면 글자 크기만 줄입니다.
  - 일반 젬, 특수 젬, 선택한 젬, 보유 젬, 합성하기 제목을 판 위쪽 띠 안으로 옮겨 가림을 없앴습니다.
  - 장착 효과, 획득한 젬, 게임 결과의 발바닥 띠는 그림 비율대로 그려서 찌그러지지 않게 했습니다.
  - 합성 화면의 젬 칸은 제목 띠 아래에서 시작합니다.
- **결과 창:**
  - 다시하기를 누르면 캐릭터 선택 화면(마지막 캐릭터)으로 갑니다.
  - Quest 아이콘은 제자리에서 페이드인으로 나타납니다. Quest Failed 아이콘은 높이를 380에서 460으로 키웠습니다.
  - 생존 시간과 획득 조각 줄을 판 크기에 맞게 다시 배치했습니다.
