# 몬스터냥터 2026 (MonsterNyangter-2026)

2025년 출시한 3인 팀 프로젝트 「몬스터냥터」를 기획자 1인이 AI와 함께 확장한 2D 로그라이크 액션 게임입니다.
기존 버전에서 구현하지 못했던 회피 · 필살기 · 무기 조합 · 추가 보스를 구현했고, 코어 루프를 **낮 사냥 / 밤 디펜스**로 바꿨습니다.

> ※ 몬스터헌터를 모티브로 한 비공식 팬 게임이며, CAPCOM과 무관합니다.

## 링크

- 트레일러 (34초): https://www.youtube.com/watch?v=vYxkJndoLKQ
- 시스템 소개 영상: https://www.youtube.com/watch?v=tCmqqBfB8t0
- 포트폴리오 (기획 · AI 협업 기록): (노션 링크)

## 이번 버전에서 바뀐 것

| 구분 | 내용 |
| --- | --- |
| 플랫폼 | Android → PC (16:9) |
| 전투 | 캐릭터 4종별 필살기와 회피, 무기 5종의 메인무기 전환과 전용 스킬, 공명 · 각성 시너지 |
| 코어 루프 | 낮에는 사냥, 밤에는 경로를 따라 몰려오는 몬스터로부터 기지 방어 (포탑 4종) |
| 성장 | 인게임 상점 → 레벨업 선택지 → 영구 강화 젬 |
| 콘텐츠 | 중간 보스 4종, 판마다 바뀌는 맵 식생, 울타리 루핑 처벌 시스템 |

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 메인무기 조준 · 공격 |
| R | 무기 전용 스킬 |
| E | 캐릭터 필살기 |
| Shift / Space | 회피 |
| Q | 아이템 사용 |
| ESC | 옵션 |

## 만든 방식

| 역할 | 담당 |
| --- | --- |
| 기획, 규칙 · 수치 결정, 지시서 작성, 플레이 검증 | 이원우 |
| 코드 구현, 측정 보고 | Claude Code (+ MCP for Unity) |
| 신규 에셋 (이펙트 · UI 패널 · 포탑 등) | ChatGPT Go |
| 지시서 정리 | Gemini · Claude 채팅 |

이번 버전에서 추가 · 수정한 코드는 Claude Code가 작성했습니다.
저는 무엇을 만들지와 그 기준(규칙 · 수치 · 완료 조건)을 정하고, 구현 전 보고를 검토해 승인한 뒤, 직접 플레이해 결과를 검증했습니다.
`CLAUDE.md`는 Claude Code에게 준 프로젝트 공통 작업 규칙입니다.

## 실행

- Unity 2022.3.62f2
- Unity Hub에서 이 폴더를 연 뒤 `Title` 씬에서 실행

## 크레딧

- 기획 · AI 협업 개발 · QA: 이원우
- 기존 버전 (2024 ~ 2025): 김범수 (개발), 박광익 (도트 에셋)
- 메인 캐릭터 · 보스 · 일반 몬스터 · 맵 타일 · 무기 도트 에셋은 박광익 님의 동의를 받아 이번 버전에서도 사용했습니다. 해당 에셋의 저작권은 제작자에게 있으며 무단 재사용을 금합니다.
- 신규 이펙트 · UI 패널 · 포탑 에셋은 ChatGPT Go로 제작했습니다.
